# odin-recipes

## About
This project involves creating a basic website containing multiple pages, each dedicated to a different recipe. Each recipe page will include a list of ingredients and step-by-step instructions for preparing the dish.

The purpose of this project is to practice and demonstrate my understanding of fundamental web development concepts.

## Skills Demonstrated
Throughout this project, I aim to demonstrate my competence in:

+ **Git:** Basic version control, including creating concise, atomic commits that each represent a single logical change.
+ **File structure:** Organizing and navigating project files and directories.
+ **HTML:** Using basic HTML elements and syntax, including:
    * Headings
    * Paragraphs
    * Ordered and unordered lists
    * Links
    * Images
